Insurance Billing Guidelines

💼 Australian Insurance Industry Standards

  • Preferred Contractor Rates: Usually 10-15% below retail
  • Payment Terms: 30-60 days typical, 90 days maximum
  • Documentation Required: Photos, moisture logs, detailed scope
  • Code Compliance: Must reference Australian Standards
  • Make Safe Limit: Usually $3,000-5,000 without approval
  • Variation Process: Written approval for scope changes >10%
  • Depreciation: Applied to contents, not structure

Major Insurers & Terms

  • IAG: 45 days, -12% rates
